\# 📚 Multi-Agent Research Assistant using LLM, RAG, LangChain \& FAISS



A powerful \*\*Multi-Agent Research Assistant\*\* built with \*\*Streamlit\*\*, \*\*LangChain\*\*, \*\*FAISS\*\*, \*\*HuggingFace Embeddings\*\*, and \*\*LLMs (via OpenRouter)\*\*.



The application allows users to upload one or more research papers (PDFs), ask questions about them using \*\*Retrieval-Augmented Generation (RAG)\*\*, summarize entire documents, and automatically switch to \*\*General Knowledge Mode\*\* when the uploaded papers do not contain the requested information.



\---



\# 🚀 Features



\### 📄 Research Paper Question Answering (RAG)



\- Upload multiple PDF research papers

\- Automatic text extraction

\- Intelligent document chunking

\- Semantic search using FAISS

\- Context-aware answers generated by an LLM

\- Source citations with page numbers

\- Retrieved document viewer



\---



\### 🤖 Multi-Agent Routing



The application intelligently routes every user query to the correct agent.



Available agents:



\- 📄 Research Paper QA Agent

\- 📑 Document Summarization Agent

\- 🌍 General Knowledge Agent



The routing logic automatically decides which agent should handle the request.



\---



\### 📑 Document Summarization



Generate concise summaries of uploaded research papers including:



\- Main Objective

\- Methodology

\- Key Findings

\- Conclusion



\---



\### 🌍 General Knowledge Mode



If the uploaded papers do not contain relevant information:



\- Similarity score is checked

\- Automatically switches to General Knowledge mode

\- Answers are generated directly by the LLM



No manual switching is required.



\---



\### 📚 Citation Support



Every research-based answer includes references such as:



```

\[1] Attention\_Is\_All\_You\_Need.pdf — Page 3

```



This allows users to easily verify where the answer originated.



\---



\### 🔍 FAISS Semantic Search



The system performs semantic similarity search using:



\- HuggingFace Embeddings

\- FAISS Vector Database



Only the most relevant chunks are sent to the LLM, reducing hallucinations and improving accuracy.



\---



\### 📂 Multiple PDF Support



Upload:



\- One paper

\- Multiple papers



The assistant searches across every uploaded document automatically.



\---



\### ⚡ Optimized Retrieval



The project uses:



\- Recursive Character Text Splitter

\- Optimized chunk size

\- Reduced overlap

\- Top-k retrieval

\- Similarity threshold



to improve both speed and answer quality.

\# 📋 How It Works



\### Step 1



Upload one or more PDF research papers.



↓



\### Step 2



The application:



\- extracts text

\- removes reference pages

\- splits documents into chunks

\- generates embeddings

\- stores them in FAISS



↓



\### Step 3



Ask any question.



↓



\### Step 4



The router decides:



\- Summarization

\- Research Question Answering

\- General Knowledge



↓



\### Step 5



If it is a research question:



\- retrieve relevant chunks

\- generate answer using RAG

\- display citations

\- show retrieved documents



↓



\### Step 6



If the question is unrelated to uploaded papers:



Automatically switch to General Knowledge mode.
